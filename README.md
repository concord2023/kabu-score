# 株スコア v3

GitHub Pages + GitHub Actions で平日自動更新する日本株スコアアプリです。

## v3で追加
- 0〜100点に拡張
- 東証プライムの騰落レシオ 6日/10日/15日/25日を市場環境として追加
- 日経225との相対強弱を追加
- IRBANKの日次株価からRSI14、出来高比、20/60日線乖離などを計算

## データ
- 株価: IRBANK API
- 騰落レシオ・日経225日次変化: 何でも定点観測の公開日次レポート

※スコアの配点は研究用の仮説で、将来のリターンを保証するものではありません。今後、バックテストで配点・閾値を検証します。

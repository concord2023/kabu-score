# 株スコア V3

週足＝方向、日足＝タイミングを基本に、判定に使った中間情報を画面で確認できるPWAです。

## 表示する中間情報
- 5/20/60日移動平均と乖離率
- 5/10/20日騰落率
- RSI(14)
- 出来高/20日平均
- 20日変動率
- 60日高値からの下落率
- 60日レンジ位置
- 13/26/52週MA乖離
- 13/26週MAの4週傾き
- 信用買い残・売り残・前週比・信用倍率
- 需給状態（重い/改善方向/軽い/中立）
- 日経平均との相対強度
- BUY暫定4条件の達成/未達

需給や0〜100点は補助的な診断情報で、未検証の指標をBUY条件にはしていません。

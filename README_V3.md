# 株スコア V3

週足＝方向、日足＝タイミングを基本に、判定に使った中間情報を画面で確認できるPWAです。

## 表示する中間情報
- 5/20/25/75/200日移動平均と乖離率
- 5/10/20日騰落率
- RSI(14)（日足・週足）
- RSIサイン：日足/週足の30未満＝売られ過ぎ、70超＝買われ過ぎ
- 出来高/20日平均
- 20日変動率
- 60日高値からの下落率
- 60日レンジ位置
- 13/26/52週MA乖離
- 13/26週MAの4週傾き
- 信用買い残・売り残・前週比・信用倍率
- ネット信用残（買い残−売り残）とネット増減（買い残前週比−売り残前週比）
- 需給状態（重い/改善方向/軽い/中立）
- 需給買いサインは「ネット需給改善＋信用倍率」を組み合わせ、売り残が少し増えただけでは点灯しない
- 日経平均との相対強度
- BUY暫定4条件の達成/未達

需給や0〜100点は補助的な診断情報で、未検証の指標をBUY条件にはしていません。


## v5: 大底・ローソク足反転サイン
- ハンマー、陽線の包み足、切り返し、毛抜き底、明けの明星などを直近3営業日で検出。
- 直近安値・60日レンジ下側などの「底値圏」と組み合わせ、「大底反転サイン」として画面上部に表示。
- 翌日/当日のフォロー確認（前日高値上抜き等）も表示。
- これは現時点ではBUY条件ではなく、見逃さないための警報レイヤー。

## レンジ抜け・再上昇シグナル
大底反転とは別に、直近20営業日の高値を終値で突破した「レンジ抜け」を検出します。突破日の出来高増加、20日MA上、突破水準維持、短期上昇、過熱度を組み合わせ、条件が揃えば「レンジ抜け・再上昇」として暫定BUY候補にします。

## 画面構成（v8）
- `index.html`: 今日の総合BUY / WATCH / AVOID と、独立サインを一覧表示。
- `signals.html`: 需給買い・大底出来高・大底反転・レンジブレイク等の点灯状況だけを横断表示。
- `detail.html?code=銘柄コード`: 1銘柄の詳細分析。チャート・移動平均・週足方向・需給・各サイン・買い条件を確認。
- 個別サインは総合BUYとは独立。サイン点灯だけで買い推奨とはしない。
## 需給取得の安定化
- 需給はウォッチリスト各銘柄について銘柄コードを厳密照合して取得。
- 市場全体の上位100件だけを見る方式は使わず、対象銘柄の取りこぼしを防止。
- 週次データは実際の `as_of` 日を保持し、欠損は推測せず `partial / unavailable` として表示。

## 需給・RSIサインの判定方針
信用倍率（買い残÷売り残）は需給の「水準」を示す指標として使い、前週比の買い残・売り残の差し引きを「方向」として併用します。信用買い残は将来の売り圧力、信用売り残は将来の買い戻し圧力になり得るため、買い残の増加が売り残の増加を大きく上回る場合は、売り残が増えていても需給買いサインにはしません。

- ネット信用残 = 買い残 − 売り残
- ネット増減 = 買い残前週比 − 売り残前週比
- ネット増減がマイナス = 需給改善、プラス = 需給悪化
- 「需給買いサイン」はネット増減がマイナス、かつ信用倍率6倍以下を基本条件とする
- ネット増減がマイナスでも信用倍率が6倍超なら「需給改善」とし、買いサインとは分離する
- 信用倍率10倍以上は原則「重い」。改善していても「高倍率だが改善中」と表示する

RSIは一般的な30/70水準を独立サインとして表示します。日足・週足とも、30未満を売られ過ぎ、70超を買われ過ぎとしてアイコン化します。RSIサイン自体は総合BUYを直接決定しません。


## テクニカル表示
- 詳細チャートはローソク足。表示MAは5日・20日・75日・200日。25日MAは指標として保持。
- ボリンジャーバンドは日足25日・±2σ、週足13週・±2σを使用。終値が±2σの外側に出た場合、日足/週足の独立サインを点灯。
- BBサインは総合BUY/SELLを直接決めず、強い上昇・下落や過熱/売られ過ぎの確認材料として扱う。

### チャート・長期移動平均
- 詳細チャートはローソク足を基本とし、5日MA・25日MA・75日MA・200日MAを表示。20日MAは判定ロジック用として残す。移動平均は現在終値を含む標準的な期間計算とする。
- 200日MAを表示・判定するため、日次株価は原則260営業日以上を取得する。IRBANK APIのページングが必要な場合はcursorで追加取得する。株式分割がある銘柄では、チャートのOHLCも調整後終値と同じ倍率で補正し、ローソク足とMAの価格尺度を統一する。
- ボリンジャーバンドは日足25日±2σ、週足13週±2σ。終値が±2σの外側に出た場合、日足・週足それぞれ独立サインを表示する。

## BUY候補スクリーニング

`recommendations.html` では、JPXの上場会社マスターに含まれる普通株式を対象に、`calc()` → `classify_regime()` → `decide()` の同じ判定経路を使ってBUY_CANDIDATEを抽出します。日次更新のGitHub Actionsで `scan_recommendations.py` が実行され、`data/recommendations.json` を更新します。新規上場など必要な履歴が不足する銘柄は無理に判定しません。

IRBANK APIの利用条件により、株価データの出典表示と利用条件を守ってください。


### データ消失防止
ユーザーが追加した銘柄は `data/custom_watchlist.json` に保持し、日次更新時に自動統合します。Daily stock update が失敗した場合は、生成データをコミットしません。これにより、失敗した更新で全銘柄が「判定不能」になる事故を防ぎます。
